# Project Codex Instructions

## Backlog completion

- For this repository, Vikunja implementation tasks may be marked done after the
  requested change is implemented locally and its acceptance criteria are
  verified, even before commit, push, PR, merge, or GitHub Pages deployment.
- Use this exception only for repository-local implementation tasks. Keep
  deployment or live-site verification tasks separate and open until they are
  actually verified against the deployed site.
